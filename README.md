# Портфолио

Многостраничный сайт-портфолио на чистом HTML, CSS и JavaScript.

## Что где лежит

```
portfolio/
├── index.html              Главная
├── projects/
│   ├── index.html          Список всех проектов (с фильтрами)
│   └── project.html        Шаблон страницы кейса (открывается как project.html?p=slug)
├── about.html              Обо мне
├── contact.html            Контакты
└── assets/
    ├── css/style.css       Все стили (цвета — переменные в самом верху)
    ├── js/data.js          ★ ВЕСЬ КОНТЕНТ САЙТА — единственный файл для правки
    ├── js/main.js          Движок (языки, рендер, фильтры) — не трогать
    └── img/                Картинки: фавиконка, фото, обложки проектов
```
