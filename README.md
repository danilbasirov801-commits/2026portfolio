# Портфолио

Многостраничный сайт-портфолио на чистом HTML, CSS и JavaScript.

## Что где лежит

```
portfolio/
├── index.html              Главная
├── projects/
│   ├── index.html          Список всех проектов (с фильтрами)
│   └── project.html        Шаблон страницы кейса
├── about.html              Обо мне
├── contact.html            Контакты
└── assets/
    ├── css/style.css       Все стили
    ├── js/data.js          ★ ВЕСЬ КОНТЕНТ САЙТА
    ├── js/main.js          Движок (языки, рендер, фильтры)
    └── img/                Картинки
```
