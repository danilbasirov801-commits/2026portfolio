# Портфолио

Многостраничный сайт-портфолио на чистом HTML, CSS и JavaScript.
Без фреймворков, без сборки, без внешних зависимостей — сайт будет
работать через десятки лет на любом хостинге.

## Что где лежит

```
portfolio/
├── index.html              Главная
├── projects/
│   ├── index.html          Список всех проектов (с фильтрами)
│   └── project.html        Шаблон страницы кейса (открывается как project.html?p=slug)
├── about.html              Обо мне
├── contact.html            Контакты
└── assets/
    ├── css/style.css       Все стили (цвета — переменные в самом верху)
    ├── js/data.js          ★ ВЕСЬ КОНТЕНТ САЙТА — единственный файл для правки
    ├── js/main.js          Движок (языки, рендер, фильтры) — не трогать
    └── img/                Картинки: фавиконка, фото, обложки проектов
```

## Как посмотреть сайт

Просто откройте `index.html` двойным кликом — сайт работает даже без
интернета и без сервера. Удобно также открыть папку в VS Code и нажать
«Live Server» (если установлено расширение) — страница будет сама
обновляться при сохранении.

## Как добавить новый проект

1. **Картинка-обложка.** Положите картинку в `assets/img/projects/`
   (например `moy-proekt.jpg`). Размер примерно 1200×750, подойдёт
   любой, лишнее обрежется.

2. **Запись в data.js.** Откройте `assets/js/data.js`, найдите список
   `PROJECTS` и добавьте объект **в начало списка** (наверху — новее на
   сайте). Готовый шаблон с пояснениями — в самом конце файла.

   ```js
   {
     slug: "moy-proekt",                    // латиницей, без пробелов
     featured: true,                        // показать на главной (первые 3)
     title: { ru: "Мой проект", en: "My project" },
     year: 2026,
     tags: ["landing"],                     // рубрики из TAGS выше в файле
     stack: ["HTML", "CSS", "JavaScript"],
     cover: "assets/img/projects/moy-proekt.jpg",
     images: [],                            // доп. картинки для галереи кейса
     summary: { ru: "Одна фраза для карточки.", en: "One line for the card." },
     description: {
       ru: ["Задача…", "Что сделал…", "Результат…"],
       en: ["The brief…", "What I did…", "Result…"]
     },
     url: "https://sajt.ru",                // "" если ссылки нет
     repo: ""                               // "" если кода нет
   },
   ```

3. **Сохраните файл** и обновите страницу. Проект появится в списке,
   в фильтрах и (если `featured: true`) на главной — вёрстку трогать
   не нужно.

Если английский не нужен, пишите в полях `en` тот же текст, что и в `ru`.

## Как редактировать остальное

Всё — в том же `assets/js/data.js`:

- **Имя, роль, тексты о себе, услуги, навыки, опыт** — объект `PROFILE`.
- **Контакты** (почта, Telegram, GitHub, что угодно) — список `CONTACTS`.
- **Рубрики-фильтры** — объект `TAGS`.
- **Подписи интерфейса** (кнопки, заголовки разделов) — объект `UI`.
- **Фото** — замените `assets/img/photo.svg` своим снимком
  (например `photo.jpg`) и поправьте путь в `PROFILE.photo`.

## Языки

По умолчанию сайт показывает русский, но если у посетителя браузер
английский — откроется английская версия. Выбор запоминается.
Переключатель RU/EN — в шапке сайта.

## Дополнительные фишки

- **Переключатель темы** (луна/солнце в шапке): светлая и тёмная.
  При первом визите тема подстраивается под систему, выбор запоминается.
- **Живой фон**: мягкие цветные пятна медленно дрейфуют по странице
  и чуть смещаются за курсором. Отключается автоматически, если у
  посетителя включено «уменьшить анимацию».
- **Кнопка «наверх»** появляется в правом нижнем углу при прокрутке.
- На странице контактов у каждого способа связи есть кнопка
  **копирования** в буфер обмена (работает и без интернета).
- Картинки в галерее кейса открываются **на весь экран** по клику;
  закрытие — кликом или клавишей Esc.

## Как выложить в интернет

**Вариант 1 — GitHub Pages (бесплатно, навсегда):**

1. Заведите аккаунт на [github.com](https://github.com), если его нет.
2. Создайте репозиторий с именем `имя.github.io` (вместо «имя» — ваш логин).
3. Загрузите туда все файлы из папки сайта (через веб-интерфейс: «uploading an existing file»).
4. Через минуту сайт будет доступен по адресу `https://имя.github.io`.

**Вариант 2 — Netlify (бесплатно, без Git):**

Зайдите на [app.netlify.com/drop](https://app.netlify.com/drop) и перетащите
папку с сайтом в окно браузера. Готово — сайт получит адрес, который потом
можно заменить своим доменом.

Любой другой хостинг тоже подойдёт: это просто файлы, которые копируются
в папку сайта как есть. Сборка не нужна.

## Пара советов «на века»

- Когда добавляете проект, заодно освежите `PROFILE.available`, год
  в подвале обновляется сам.
- Реальные скриншоты проектов выглядят в разы лучше заглушек —
  замените SVG-обложки на скриншоты или снимки.
- После покупки домена добавьте в `<head>` каждой страницы
  `<link rel="canonical" href="...">` и Open Graph теги — для красивых
  ссылок в мессенджерах.
